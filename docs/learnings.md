# Learnings

The lead writes this at handoff. 80 lines or fewer; never imported or auto-loaded.
Format: `## <topic>`, then `- **Rule.** What happened, with a date or numbers.`
When a lesson becomes a standing rule, move it to AGENTS.md (workers) or docs/roles/lead.md (lead) and delete it here.

## Claude Code memory
- **Import AGENTS.md explicitly.** With a CLAUDE.md present, Claude Code never auto-loads AGENTS.md; "read AGENTS.md first" in prose is not an import. Until 2026-10-15 no Claude session got the project rules (docs/research/memory-setup.md §0).
- **An `@name` in prose is an import.** AGENTS.md's "Read @SPEC.md first" would have pulled SPEC.md (21k chars) into every session. Write file names in backticks.
- **No settings file is lead-only.** Worktrees read the main checkout's `.claude/settings.local.json` and its untracked `.claude/commands`, `agents` and `skills`. Lead-only config goes on the lead's command line (`docs/roles/lead.sh`).
- **Never truncate injected state.** Hook output over 10,000 chars becomes a path plus a 2,000-char preview, and cutting STATE.md drops "Next 3 actions" at the bottom. Refuse and say so instead.
- **Generate copies, don't hand-write them.** The DECISIONS index is generated by state-check.sh; a hand-kept third copy of each status would drift.
