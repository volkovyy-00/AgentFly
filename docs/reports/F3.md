## 2026-10-18 21:58

### What changed
- **Order.** `_remove_folder`: delete old `.AgentFly-removing-*` leftovers, `os.rename` the folder to `.AgentFly-removing-<time_ns>`, then `rmtree`. Used by `uninstall` and by `_undo_first_install` (the cleanup of a failed first install, now its own function). Strip of our entries still comes first. `is_installed` and `uninstall` know the leftovers.
- **Foreign entries.** `hooks_file.commands()` gives parsed command strings; `_strip_hooks` refuses if any remaining one contains `<root>/`. An unparseable file is checked as raw text after decoding `\/` and `\uXXXX`. Refusal comes before any backup or write: snapshot-equal in the tests.
- **Backups.** `Layout.backups` is `/Library/Application Support/Cursor/agentfly-backups/` (timestamped, root-owned, survives uninstall). `_rewrite_hooks` backs up the current text before every rewrite; install takes its backup before writing. The read-back-failed restore writes directly on purpose (a full disk must not stop it); the backup test exempts nothing else.
- **Exact give-back.** The splice cannot tell "no hooks key" from "empty hooks". Install records `original_backup`, `original_sha256`, `written_sha256` in `hashes.json` (`hooks_file` section, added by the installer; `records.py` untouched). Uninstall writes the original back only if the file's hash is still `written_sha256` and the backup's hash is `original_sha256`; otherwise it keeps the splice result. A backup name that is not a plain file name is ignored.
- **Restore.** `_restore` renames the new tree aside and the old one back (no `rmtree`, skips the first step if `python/` is already missing, undoes it if the second fails). On failure the graveyard is kept, its path is printed to stderr and added as a note.
- **Errors.** `uninstall` turns `OSError` into `InstallError("cannot finish removing AgentFly (<reason>); run `agentfly uninstall` again")`; `cli/uninstall.py` also catches a bare `OSError`: one line, exit 1.
