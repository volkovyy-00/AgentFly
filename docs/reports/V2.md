### Choices I made (the brief left them open)
- A flag cluster stores only its first letter: `ls -la` → `ls -l<arg>`, `mysql -pX db` → `mysql -p<arg> <arg>`. `-pX` and `-la` cannot be told apart, so any cluster longer than one letter could carry a value. Cost: `rm -rf x` is stored as `rm -r<arg> <arg>`.
- `scripts/setup_credentials.sh`, `.env.example` and the AGENTS.md path lines were edited although they are outside "Touches": without it the README credentials command would write a file nobody reads.
- The hook log's folder and file are owner-only, because until V2b the log still holds raw shell commands.

### Gaps for other cards (not fixed here)
- V2b: the client still posts to 8787 and has no port override, so no hook-to-recorder run was possible. Its log still holds the raw `command`. Plain allow when the server is down is unchanged.
- `install.sh` (out of scope) still runs `mkdir -p ~/.config/flightrecorder` and prints `logs/events.jsonl`; running it re-creates an empty old folder (harmless, it is not read after the first start).
- HOOKS.md still names `recorder/`, `~/.config/flightrecorder` and `uvicorn recorder.app:app`; `ui/src/graph/snapshot.ts` and `ui/src/graph/mock.ts` mention the old name or the old `rm -rf <arg>` form.
- Cleaner, outside the brief's shapes: a separate dotted word after a web tool (`curl -d token.abc`) is stored as a host name. `--name value` with a secret that is also an existing project file is stored as the path.
- The old token is deleted on migration. A hackathon hook client that still reads `~/.config/flightrecorder/token` will fail open until updated.
- The wheel test needs `uv` and, the first time, the network (hatchling). It skips with a reason on a network error and fails on any other error.
- Nothing under the real `~/.config/flightrecorder`, `~/.cursor`, `/Library/Application Support/` or `/tmp/af-*` was touched. No recorder ran on 8787. Before and after listings of `~/.config/flightrecorder` match, and `~/.config/agentfly` and `~/.local/share/agentfly` do not exist yet.
